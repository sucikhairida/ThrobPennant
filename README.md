# ThrobPennant

ThrobPennant enables real-time, high-performance cryptocurrency transaction analysis via a multi-threaded, auto-scaling orchestrator and manager framework.

The key benefits of using ThrobPennant include:

- ThrobPennant enables real-time, high-performance cryptocurrency

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ThrobPennant.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
